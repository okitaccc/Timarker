# 事刻 Timarker

> 把重要的事，放进时间里。

Timarker 是一款面向 Windows 的本地优先个人时间与事务管理应用。它把“计划要做什么、现在推进什么、时间实际花在哪里、事后留下了什么”放在同一套工作流中，覆盖事项、项目、提醒、今日清单、番茄钟、时间追踪、统计、复盘、便签与收藏夹。

当前版本为早期测试版，适合个人使用、功能体验和协作测试。它不是医疗、生产运维或其他不能容忍提醒遗漏的关键通知系统。

## 产品定位

Timarker 的核心流程是：

```text
计划 → 执行 → 回顾
```

- **计划**：今日、事项、日历和项目回答“要做什么”。
- **执行**：下一步、今日清单和番茄钟帮助推进当前行动。
- **回顾**：时间追踪、时间统计、复盘和事项历程回答“实际做了什么”。
- **工具**：收藏夹和便签整理辅助信息，不替代事项或项目。

几个容易混淆的概念：

- **事项**是可以被安排、提醒和处理的行动。
- **当天内完成**只要求在某一天完成，不强制指定当天的具体时间；提醒可以关闭。
- **项目**是带顺序和进度的多步骤目标，每个步骤仍可独立安排时间与提醒。
- **收藏夹**只聚合事项，不改变事项本身的状态和分类。
- **便签**是不要求日期与完成状态的临时信息，可固定到桌面。
- **时间追踪**是在用户主动启用后采集的本机前台应用活动。
- **复盘**是对成果、问题、收获和后续行动的主动记录。

## 已实现功能

### 事项与提醒

- 支持一次性事项、截止事项、时间段、当天内完成、周期事项、习惯、生日、纪念日和“可能要做”。
- 可分别设置开始时间、截止时间、优先级、备注、词条以及是否提醒。
- 支持提前提醒、再次提醒次数与间隔、稍后提醒和延期事项。
- 提醒去重，避免同一提醒在刷新或重复检查时连续弹出。
- 周期事项支持按天、周、月、年重复，以及工作日、指定星期、第几个星期几、每月最后一天等规则。
- 支持周期暂停、结束条件、跳过本次、调整单次发生时间和漏做处理策略。
- 生日支持阳历、农历、闰月、未知出生年份和年龄显示。
- 纪念日支持周年、累计天数和自定义里程碑天数。
- 不同事项类型使用不同颜色，便于在列表和日历中识别。

### 今日、日历与项目

- “今日与未来”支持状态筛选、标题/词条搜索、完成、延期、编辑和删除。
- “下一步”基于未完成事项提供更聚焦的处理入口。
- 月历按日期展示事项，并提供生日、纪念日、周期事项和普通事项的数量摘要。
- 项目拥有独立模型，可设置目标、总体截止日期、顺序步骤和下一步行动。
- 项目步骤可单独设置日期、提醒和完成状态，也可批量顺延未完成步骤。
- 收藏夹拥有独立模型，可将同一事项加入多个收藏夹。

### 今日清单与专注

- 今日清单以屏幕侧边悬浮窗展示当天待处理事项。
- 向右拖动事项可完成，向左拖动可进入编辑。
- 清单窗口可调整高度，并可设置是否随 Timarker 启动自动显示。
- 内置番茄钟；离开番茄钟页面后计时仍会继续，并通过 Windows 通知提示阶段结束。
- 可将临近事项打开为悬浮倒计时。

### 时间追踪与统计

- 时间追踪为可选功能，启用后记录前台应用、起止时间、持续时间和空闲状态。
- 时间轴按时间段展示应用活动，悬停可查看该段时间的应用、标题、分类和时长。
- 活动明细支持查看标题、应用、分类、开始、结束和持续时间。
- 可为应用或匹配特定窗口标题的活动建立独立分类规则。
- 活动可关联项目或事项；活动分类与事项词条/分类互相独立。
- 时间统计可按一天、一周、一月等范围汇总应用、活动分类和项目耗时。
- 可选择是否保存窗口标题，并支持排除不希望记录的进程。
- 可配置数据保留天数、手动清空时间追踪数据，并定期执行整理与清理。
- 时间追踪数据使用 SQLite 保存，启用 WAL、完整性检查、每日备份、损坏隔离和备份恢复。

### 复盘、事项历程与人物

- 完成事项、项目步骤、生日或纪念日时可自动留下活动记录。
- 可手动补记每日成果、收获、问题和下一步。
- 事项历程保留状态变化和发生记录，便于回看周期事项的每次处理结果。
- 人物资料可关联生日、纪念日和其他相关事项。

### 便签与悬浮窗

- 支持便签标题、正文、词条、搜索和置顶。
- 编辑内容未保存时切换便签会进行保护性提示，降低误丢内容的风险。
- 双击便签可打开桌面悬浮窗，双击悬浮窗可再次编辑。
- 悬浮便签可在编辑时继续显示，但不会挡在编辑窗口上方。

### 外观、窗口与系统集成

- 支持浅色、深色和跟随系统主题。
- 支持全局字体缩放。
- 支持主窗口自定义背景图片、显示方式和透明度。
- 可按需启用或隐藏日历、项目、下一步、今日清单、番茄钟、时间追踪、复盘、统计、事项历程、收藏夹和便签等模块。
- 记忆主窗口的位置、大小和最大化状态；重新打开时恢复到上次位置，失效时回到可见屏幕区域。
- 支持最小化到系统托盘、开机启动和单实例运行；再次启动会唤醒已有窗口。
- 支持简体中文与 English，英文界面仍在持续补齐。

### 插件

- 支持安装 `.tmplugin` 或 `.zip` 插件包，并在设置中启用、停用或卸载。
- 插件可通过实现 `ITimarkerPlugin` 提供独立功能页面。
- 示例插件位于 `samples/Timarker.SamplePlugin`，开发说明见 [docs/plugins.md](docs/plugins.md)。

插件与 Timarker 运行在同一进程中，没有安全沙箱。请只安装来源可信的插件。

## 数据与隐私

Timarker 不要求账号，事项、项目、便签、复盘和时间追踪数据默认只保存在本机：

```text
%LocalAppData%\Timarker
```

主要文件和目录：

```text
events.json          事项、项目、收藏夹、便签、人物和复盘数据
events.bak           事项数据的最近可用副本
Backups\             事项数据滚动备份
settings.json        主题、窗口、功能开关和隐私设置
activity.db          时间追踪 SQLite 数据库
ActivityBackups\     时间追踪数据库备份
Plugins\             已安装插件
Corrupt\             自动隔离的损坏数据文件
Logs\                崩溃日志（存在异常时）
```

时间追踪默认不会上传数据。窗口标题可能包含文件名、网页标题或其他私人内容，因此必须由用户主动选择是否保存。提交 Issue 前请遮盖截图中的私人事项，不要公开上传完整数据目录。

从旧版 Timeline 升级时，应用会在首次启动时迁移原数据目录。卸载程序默认保留用户数据，便于重新安装后继续使用。

## 安装

1. 打开仓库的 [Releases](https://github.com/okitaccc/Timarker/releases) 页面。
2. 下载最新的 `Timarker-Setup-<版本号>.exe`。
3. 运行安装程序并按提示选择是否创建桌面快捷方式。

安装程序默认安装到当前用户目录，不要求管理员权限，并会注册标准卸载程序：

```text
Windows 设置 → 应用 → 已安装的应用 → 事刻 Timarker → 卸载
```

当前安装包尚未进行商业代码签名，Windows 可能显示 SmartScreen 提示。请只从本仓库 Releases 页面或可信测试人员处获取安装包。

## 从源码运行

环境要求：

- Windows 10/11 x64
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

```powershell
cd src\Timarker
dotnet run
```

当前正式应用使用 Windows Forms。`src/Timarker.WinUI` 是界面迁移原型，不是默认发布入口。

## 测试

核心日期、周期、提醒去重、状态流转、存储恢复、当天内完成和时间统计逻辑均有自动化测试：

```powershell
dotnet test tests\Timarker.Core.Tests\Timarker.Core.Tests.csproj
dotnet test tests\Timarker.Plugin.Tests\Timarker.Plugin.Tests.csproj
```

## 构建安装包

除 .NET 8 SDK 外，还需要安装 [Inno Setup](https://jrsoftware.org/isdl.php)。在项目根目录运行：

```powershell
.\build-installer.ps1 -Version 0.1.1
```

生成结果：

```text
artifacts\installer\Timarker-Setup-0.1.1.exe
```

## 当前限制

- 仅支持 Windows，暂不提供云同步和跨设备通知协调。
- 时间追踪依赖 Windows 前台窗口信息，部分提权应用或系统窗口可能只能取得进程名。
- 插件是受信任的进程内代码，尚无权限隔离、签名验证和插件市场。
- WinUI 版本仍是原型，当前安装包发布 Windows Forms 主程序。
- 英文界面和键盘/屏幕阅读器可访问性仍需继续完善。
